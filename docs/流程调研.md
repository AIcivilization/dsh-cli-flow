# 流程从哪来

内置流程不是凭空想的，是看了国内现成产品的节点结构后整理的。这里只借鉴**步骤怎么分、节点之间怎么连**，提示词都是自己写的，没有用别家的内容。

调研时间：2026 年 11 月。来源多数是产品宣传页和第三方文章，不是官方文档，细节可能和产品实际有出入。

## 整理出的流程

### AI 短剧

| 步骤 | 依据 |
|---|---|
| 创意 → 大纲 → 剧本 | 各家共同的起点 |
| 剧本拆解（场次、人物、场景、道具） | 多数工具的第一步就是“剧本解析” |
| 人物设定、场景设定 | 先定资产，保证人物前后一致 |
| 分镜 | LibTV 的宫格分镜、其他工具的分镜节点 |
| 定妆照、关键帧、视频片段、配音 | 单镜头生成，这几步要出图出视频的工具，所以是“要填入”的卡片 |
| 剪辑清单 | 后期；有的产品能导出到剪映 |

### PPT 演示

各家路径基本一致：主题或文档 → 大纲 → 风格 → 每页内容 → 校对配图 → 导出。我们把受众分析放在最前面，因为它决定后面所有内容；另加了演讲稿和问答准备，这两步是有的产品提供的“演讲话术”。

### 短视频口播

文案 → 素材 → 配音 → 字幕 → 剪辑是通用结构，前面再加选题和开头钩子，后面加封面和发布文案。

### 电商商品上架

底图 → 卖点 → 主图、场景图、细节图 → 详情页 → 多平台素材。

## 从这些产品学到的设计

| 看到的做法 | 我们怎么用 |
|---|---|
| LibTV 的无限画布：文字、图片、视频、音频节点，节点可手动输入也可由模型生成 | 每张卡片都能手动填入，也能由工具生成 |
| LibTV 给 Agent 开 Skill 接口 | `cli_flow` 工具和 `dsh-cli-flow` skill，让 dsh 的 AI 操作卡片 |
| 角色资产有引用关系，改了角色图能找到受影响的分镜 | 引擎记录每个版本用了哪些上游，上游变了下游标“要重跑” |
| 比稿：同一步出多个结果挑一个 | 比稿卡片，选完才继续 |

没有照搬画布：我们的主要操作者是 dsh 的 AI，人是确认和挑选的，右侧栏的卡片列表够用，也更省事。需要自由连线时，可以让 AI 现场拼流程。
